# Web3 Credentials Landing Page

## What's Included

A single-page website with:
- Hero section with clear value prop
- Problem statement (why generic swag sucks)
- Product tiers (Standard $2.50, Premium $5, Elite $12)
- Why choose us (features/benefits)
- Trust signals (stats)
- Contact form with quote request

## To View Locally

1. Open `index.html` in any browser
2. That's it—it's pure HTML/CSS/JS, no build needed

## To Deploy

### Option 1: Netlify (Easiest)
1. Go to netlify.com
2. Drag and drop the `website` folder
3. Done—you get a free URL like `yoursite.netlify.app`

### Option 2: Vercel
1. Go to vercel.com
2. Import this folder
3. Deploy

### Option 3: Custom Domain
1. Buy a domain (namecheap.com, godaddy.com)
2. Use any hosting (Netlify, Vercel, GitHub Pages)
3. Point domain to hosting
